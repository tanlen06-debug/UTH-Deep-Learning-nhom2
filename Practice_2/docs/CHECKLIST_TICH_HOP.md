# Checklist tích hợp

## Trước Pull Request
- [ ] Notebook chạy từ đầu đến cuối
- [ ] Không có đường dẫn `C:\...` hoặc `D:\...`
- [ ] Không commit dữ liệu/checkpoint/log lớn
- [ ] Có output và nhận xét
- [ ] Chỉ sửa file thuộc phạm vi được giao

## Trước merge
- [ ] Không xung đột với file thành viên khác
- [ ] Kết quả đã ghi vào `results/tables/metrics.csv`
- [ ] Có ít nhất một người kiểm tra
