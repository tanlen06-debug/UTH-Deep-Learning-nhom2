# Quy tắc tránh xung đột

1. Mỗi file dùng chung chỉ có một người phụ trách chính.
2. Không hai người cùng chỉnh một notebook trong cùng thời điểm.
3. Khi cần sửa file ngoài phần mình, phải báo nhóm trưởng.
4. Mỗi Pull Request chỉ nên chứa một phần việc rõ ràng.
5. Không đổi tên thư mục hoặc file khi chưa thống nhất.
6. Sau khi merge, các thành viên cập nhật branch của mình từ nhánh chính.
