# Member 04 – MSE vs MAE Loss

## Trách nhiệm
- Xây dựng training experiment với MSE Loss.
- Xây dựng training experiment với MAE/L1 Loss.
- Giữ các điều kiện khác giống nhau để so sánh công bằng.
- Theo dõi train/validation loss và MAE.
- Tổng hợp Test MAE, MSE và RMSE.

## Deliverables
- Notebook/script training cho MSE.
- Notebook/script training cho MAE.
- Bảng so sánh hai loss functions.
- Biểu đồ loss/metric theo epoch.

## Acceptance criteria
So sánh phải dùng cùng preprocessing, split, model architecture và các hyperparameters chính, chỉ thay đổi loss function khi thực hiện thí nghiệm MSE vs MAE.
