# Member 06 – Evaluation & Report

## Trách nhiệm
- Xây dựng pipeline evaluation trên test set.
- Tính MAE, MSE và RMSE.
- Vẽ Actual vs Predicted Age.
- Phân tích phân bố prediction error.
- Tổng hợp kết quả các experiment.
- Viết Discussion, Conclusion và nội dung báo cáo/thuyết trình.

## Deliverables
- Notebook evaluation.
- Bảng kết quả cuối cùng.
- Các biểu đồ đánh giá.
- Phần Discussion/Conclusion của coursework.
- Danh sách câu hỏi có thể được giảng viên hỏi khi bảo vệ.

## Acceptance criteria
Không chỉ báo cáo con số; phải giải thích model sai bao nhiêu tuổi trung bình, model nào tốt hơn và tác động của loss/augmentation.
