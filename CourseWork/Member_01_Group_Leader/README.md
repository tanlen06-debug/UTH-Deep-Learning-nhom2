# Member 01 – Group Leader

## Trách nhiệm
- Quản lý tiến độ và GitHub repository.
- Chốt kiến trúc tổng thể và pipeline của coursework.
- Tích hợp các phần của thành viên.
- Kiểm tra tính nhất quán giữa data, model, training và evaluation.
- Chạy kiểm thử notebook cuối cùng.
- Chuẩn bị phần tổng hợp và điều phối thuyết trình.

## Deliverables
- `01_project_overview.ipynb` hoặc notebook tổng hợp.
- `final_coursework.ipynb` sau khi tích hợp.
- Checklist kiểm tra trước khi nộp.
- Nội dung tổng hợp kết quả cuối cùng.

## Lưu ý
Không tự ý thay đổi code lõi của thành viên khác nếu chưa trao đổi. Ưu tiên review Pull Request trước khi merge vào `main`.
