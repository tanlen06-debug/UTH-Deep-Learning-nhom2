# Practice 3 - Notebooks

Practice 3 is organized like Practice 2: each group member has one notebook in this folder.

| Notebook | Member | Responsibility |
|---|---|---|
| `01_group_leader_integration.ipynb` | TV1 - Group Leader | Integration, final checks, summary |
| `02_sentiment_analysis.ipynb` | TV2 | Exercise 1 - Sentiment Analysis with Hugging Face |
| `03_dataset_preprocessing.ipynb` | TV3 | Exercise 2 - Dataset and preprocessing |
| `04_model_tokenizer.ipynb` | TV4 | Exercise 2 - Pretrained model and tokenizer |
| `05_training_finetuning.ipynb` | TV5 | Exercise 2 - Training arguments, Trainer, fine-tuning |
| `06_evaluation.ipynb` | TV6 | Exercise 2 - Evaluation and analysis |

## Working rule

Each member develops in their assigned notebook. Shared decisions such as the dataset and pretrained model should be synchronized before dependent sections are finalized. The group leader performs the final integration check.
